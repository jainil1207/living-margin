# Product Requirements Document (PRD): The Living Margin

## 1. Project Overview
**The Living Margin** is a dynamic online library system designed to transform solitary reading into a collaborative and highly personalized experience. 

### 1.1 Core Problem
Traditional e-readers and digital libraries isolate the reader. Notes are hidden, highlights are private by default, and there is no social layer to discover how others are interpreting the same text.

### 1.2 Core Solution
A platform where readers can dynamically interact with texts, leave "margin notes" anchored to specific sentences, share insights publicly or privately, and build a personalized knowledge graph.

## 2. Target Audience
- Avid readers and book clubs.
- Students and researchers who need robust annotation tools.
- Thought leaders who want to share their reading notes publicly.

## 3. Core Features
- **Dynamic Annotations**: Highlight text and leave rich margin notes anchored to specific sentences.
- **Social Reading**: Follow friends, see public highlights, and discuss passages directly in the margins.
- **Smart Bookshelf**: Organize digital libraries, track progress, tag books, and search through past annotations.
- **Authentication**: Secure user login and signup.

## 4. Success Metrics
- Daily Active Users (DAU) and Weekly Active Users (WAU).
- Average session length per reader.
- Number of annotations created per user per week.
- Conversion rate from Landing Page to Account Creation.
